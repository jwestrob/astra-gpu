# Results

Compact machine-readable environment inventories, benchmark summaries, and
validation summaries live here. Results must never be fabricated or inferred
from incomplete runs.

Raw HMMER output, verbose oracle JSONL, profiler exports, and extracted
biological records stay local and are ignored. Pilot timing is explicitly
labeled and cannot be promoted to a reportable result. `datasets.json` freezes
external source paths and digests; `hmm-inventory.json` records profile-length,
format, cutoff, and quantile coverage.
